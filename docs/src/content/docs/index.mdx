## Resumen Ejecutivo

El proyecto `social-neighborhood-front-end` es una aplicación React que sirve de interfaz al sistema Social Neighborhood. El análisis de deuda técnica identificó problemas en cuatro dimensiones:

<CardGrid>
  <Card title="Arquitectura" icon="error">
    URLs y configuración dispersas (`window.$dir`), componentes que mezclan UI + lógica + API, `AuthContext` definido pero nunca conectado, credenciales embebidas en el código fuente.
  </Card>
  <Card title="Calidad" icon="information">
    Ausencia de pruebas unitarias en componentes críticos, dependencias desactualizadas con vulnerabilidades conocidas (Axios, Firebase), dos backends mezclados sin capa de abstracción.
  </Card>
  <Card title="Mantenibilidad" icon="setting">
    Acoplamiento fuerte a `localStorage`, lógica repetida para rutas/errores/notificaciones, uso extensivo de `console.log` en producción.
  </Card>
  <Card title="CI/CD" icon="approve-check-circle">
    Pipeline implementado en GitHub Actions con build, tests, SonarCloud y OWASP Dependency Check activos.
  </Card>
</CardGrid>
